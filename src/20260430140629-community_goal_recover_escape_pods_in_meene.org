Following a skirmish with a group of mercenaries, security forces in the
[[id:9c59e7e7-1737-43a9-ac67-e818f6d1677d][Meene]] system have launched an operation to capture enemy agents in order
to investigate the attack.

Security Chief [[id:0bd61b69-66c6-4be7-abfc-0395734bdc72][Harper Vargas]] of the [[id:f36afa96-d3df-40d8-bf67-13cbe388e889][Meene Defence Force]] gave the
following statement:
The mercenaries were targeting [[id:4551539e-a6b2-4c45-8923-40fb603202b7][Ram Tah]]'s [[id:1129599f-efa9-4186-969e-eb09ae9d3c2d][Phoenix Base]], but it's clear
they were just hired hands. We need to recover as many surviving
mercenaries as we can and interrogate them, so we can find the real
culprits.

The [[id:706c70bc-7bb0-4b7a-ad90-04112bffaf73][Independent HIP 29241 Green Party]], which is overseeing the
initiative, has requested commanders recover Occupied & Damaged Escape
Pods in the system and bring them to Felice Dock for this purpose.
